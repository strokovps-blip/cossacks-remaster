# Cossacks Input Remaster

Патч для **Cossacks: The Art of War**, позволяющий нормально играть на современных системах (Windows 10/11). В оригинальном виде игра на них работает неверно: ломаются вывод картинки, цвета и темп кадров. Патч заменяет устаревший DirectDraw игры своим выводом через Direct3D 11 (`ddraw.dll`), игровые файлы не изменяются.

## Что стало доступно
- Корректный вывод картинки на современных ПК: Direct3D 11, вертикальная синхронизация, масштабирование на любой экран.
- Исправлены ограничитель кадров (рывки), палитра (неверные цвета интерфейса), курсор.
- Плавный скролл камеры без смещения интерфейса.
- Настройка картинки в `remaster.ini`: масштабирование (3 режима), резкость, гамма, контраст, насыщенность, виньетка, сглаживание, FXAA, смешение кадров.
- Сборка без логов и сбора данных (~225 КБ), файл настроек читается один раз при запуске.

## Установка
Готовый файл: раздел **Releases**.
1. Закройте игру. Сделайте копию `ddraw.dll` из папки игры, если он там уже есть (в оригинальной установке его нет).
2. Распакуйте `ddraw.dll` и `remaster.ini` в папку игры рядом с `dmcr.exe`.
3. В игре желательно выбрать разрешение Full HD 1080 (1920×1080) и ползунок скорости игры на 75–80%.
4. Запустите игру. Картинку можно подстраивать в `remaster.ini` (читается один раз при запуске, после правки перезапустите игру).
5. Откат: удалите `ddraw.dll` из папки игры.

Требуется Windows 10/11 и видеокарта с Direct3D 11.

Проверено на версии игры v1.30 «Последний довод королей» (вторая).

## Сборка
Исходники в `ddraw-d3d11/`. Нужен MSVC (x86): запустите `ddraw-d3d11/build.bat`.
